# Njörðr, the GameCult economy daemon

The specification moved to its owning repository on 2026-09-11:
`GameCult/Njordr`, file `docs/architecture/njordr.md`
(https://github.com/GameCult/Njordr). This file is a pointer so Ghostlight's
map and integration notes keep resolving; it carries no authority.

What Ghostlight owes Njörðr is unchanged and lives here: the outbound consumer
batch shaped as Njörðr's signal surface (custody, pressure and dependency,
route, and event deltas), market mirrors as externally controlled subjects,
several per world, and consumer patches carrying prices as witnessed facts,
shortages as pressures, and realized trades as custody with a receipt.
